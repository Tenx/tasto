# TASTO — Project Instructions

Single-file marketing site for **tasto.world**. Customers browse visual styles, pick one, and copy a portable brand-identity prompt (`vi`) to paste into any AI tool.

- **Stack:** one `index.html` (hero + gallery + modals) + `images/` folder. No build step.
- **Live:** https://www.tasto.world · **Deploy:** `npx vercel --prod` (project `epiphanyai/tasto`)
- **Styles:** 32, each `images/styles/{key}/preview.png` + a `styles[key]` entry in `index.html`.

## Adding a new style

Register the style in **4 places** in `index.html`:

1. **`styles` object** — `<key>: { title, meta, vi }`. Write `vi` with the VI Prompt Template (7 sections, plain language, no CSS). Extract the real palette from `preview.png`.
2. **`vibeCategories`** — `<key>: '<category_key>'`
3. **`styleImageMap`** — `<key>: 'images/styles/<key>/preview.png'`
4. **`vibePalette`** — `<key>: ['#h1','#h2','#h3']` — **fallback gradient only** (shown while the preview image loads). NOT the recolor source; any 3 representative colors are fine.

Full step-by-step (image gen, vibe card, deploy) lives in project memory: `MEMORY.md`.

## ⚠️ PALETTE section is load-bearing — the recolor UI parses it

The modal's color swatches are generated by **`parsePaletteHex(id, styleData)`** in `index.html`, which regex-extracts every `#rrggbb` from the `\nPALETTE\n…` block (up to the next `SECTION` heading), deduped in order. Dragging a swatch replaces that exact hex everywhere in the copied prompt (`applyColorsToPalette`) and highlights it. To keep every style consistent:

- **Real 6-digit hex only** — `#rrggbb`, lowercase, exactly 6 digits. NO `#fff` shorthand (the regex only matches 6 digits).
- **Every recolorable color MUST appear as a hex inside PALETTE.** Colors mentioned only in AESTHETIC/FORM get no swatch.
- **Heading must be exactly `PALETTE`** on its own line, or the section regex misses it.
- **Swatch count = distinct hex in PALETTE** (currently 3–8). `renderPaletteSwatches` renders N dynamically; CSS `flex-wrap` handles overflow. There is **no fixed 3-color assumption** — do not reintroduce one.
- **Reuse the same hex** in the prompt body wherever you name that color, so recolor + highlight stay in sync automatically.
- `vibePalette[key]` does **not** need to match the PALETTE hex.

## VI Prompt Template (the `vi` field)

One portable, tool-agnostic prompt customers paste into any LLM / code gen / image gen / design tool, for BOTH physical goods (t-shirts, mugs, caps, stickers, tape measures, packaging) and digital products (sites, apps, landing pages). **NO mode switches, NO code/CSS blocks.**

**Skeleton vs skin:** skeleton = timeless style DNA (grid, type, form, mood) — never drop. Skin = the ACTUAL palette pulled from `preview.png`. Resolve conflicts toward the image but keep the skeleton coherent.

**Structure (7 sections + fill-in line):**
```
Brand: [BRAND] — Visual identity in the <Style Name>.

AESTHETIC       one paragraph: soul / origin / worldview
PALETTE         intro line, bulleted exact hex + names, then a color-use rule
TYPOGRAPHY      display + body faces, weights, grid/alignment
FORM & LAYOUT   shapes, edges, texture, composition, logo/mark
MOTION          how it animates (or "static/minimal")
MOOD            4–5 adjectives + a cultural reference
APPLICATION     one paragraph: identity on PHYSICAL goods (material+print)
                AND DIGITAL products (UI/grid/motion); end with
                "the logo/mark stays identical across every medium"
DO: ...         one line of positive rules
DON'T: ...      one line of prohibitions

Now apply this identity to: [describe the product — e.g. a t-shirt, a mug, a landing page, an app screen, product packaging].
```

Reference examples in `index.html`: `swiss_style`, `cyberpunk`.
